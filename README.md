# OKX Spot Telegram Signal Bot

بوت تداول Spot لمنصة OKX يعتمد على توصيات تصل من قروبات تيليجرام عبر حسابك الشخصي (وليس بوت).  
الكود جاهز للنشر على GitHub والتشغيل على Railway.

## الفكرة العامة ببساطة
1. البوت يراقب قروبات تيليجرام المحددة.
2. عند وصول توصية مطابقة للنمط، يفتح صفقة Spot في OKX.
3. يضع وقف خسارة أولي حسب التوصية.
4. عندما يصل السعر إلى الهدف الأول (TP1) يُلغى وقف الخسارة السابق، ويبدأ Trailing Stop بنسبة 2%.
5. البوت يدير رأس المال بحيث يقسّم الرصيد بالتساوي ولا يفتح أكثر من 4 صفقات في نفس الوقت.

## كيف يحدد البوت تحقق الهدف الأول (TP1)
البوت يجلب سعر السوق الحالي من OKX بشكل دوري، وعندما يصبح السعر **أكبر أو يساوي قيمة TP1** يبدأ تفعيل الـ Trailing Stop.  
هذا المنطق موجود في ملف `strategy.py` داخل دالة `_monitor_position`.【F:strategy.py†L56-L78】

## أفضل طريقة لتطبيق Trailing Stop بنسبة 2% على Spot في OKX
هناك طريقتان:
1. **Trailing Stop مُدار من البوت (الموجود في الكود الحالي):**
   - البوت يراقب السعر باستمرار.
   - يحفظ أعلى سعر بعد TP1.
   - يحدّث وقف الخسارة إلى: `أعلى سعر × (1 - 0.02)`.
   - إذا هبط السعر إلى هذا المستوى يُغلق الصفقة فورًا.  
   هذه الطريقة مرنة وتعطيك تحكمًا كاملًا حتى لو لم تتوفر أوامر Trailing Stop Spot في حسابك أو منطقتك.

2. **Trailing Stop بأمر Algo من OKX (اقتراح بديل):**
   - يمكن استخدام أوامر `order-algo` في OKX إذا كانت متاحة للحساب.
   - هذه الطريقة تقلل اعتمادك على البوت للتنفيذ اللحظي.
   - تحتاج ضبط `algoType` المناسب حسب واجهة OKX API الخاصة بمنطقتك.

الكود الحالي يستخدم الطريقة الأولى لأنها أكثر ثباتًا ولا تعتمد على توفر نوع أمر معيّن.

## تنبيهات في حال فشل التنفيذ أو التعارض
البوت يسجّل تحذيرات وأخطاء في السجل (Logs) في الحالات التالية:
- فشل وضع أمر الشراء.
- فشل وضع أمر وقف الخسارة.
- فشل جلب السعر أو البيانات.
- وصول البوت للحد الأقصى للصفقات المفتوحة.  
كل هذه الرسائل تظهر عبر `logging` في الملفات الأساسية.【F:strategy.py†L19-L131】

## صيغة التوصية المتوقعة
يتم التعرف على التوصيات وفق النمط التالي (يمكن تعديله):
```
BUY BTC/USDT entry 63000 SL 60000 4H TP1 66000
```
**ملاحظات:**
- الكلمة `4H` بعد وقف الخسارة تعني شرط "إغلاق شمعة 4 ساعات أقل من السعر".
- الإشارة يجب أن تحتوي على SL و TP1 على الأقل.  
النمط موجود في `telegram_listener.py`.【F:telegram_listener.py†L9-L45】

## إعداد متغيرات البيئة (Railway)
ضع هذه القيم في Railway → Variables:

| المتغير | الوصف |
|--------|-------|
| `OKX_API_KEY` | مفتاح OKX |
| `OKX_API_SECRET` | السر الخاص بـ OKX |
| `OKX_API_PASSPHRASE` | عبارة المرور في OKX |
| `OKX_BASE_URL` | اتركها افتراضيًا أو ضع `https://www.okx.com` |
| `TELEGRAM_API_ID` | API ID الخاص بتيليجرام |
| `TELEGRAM_API_HASH` | API HASH الخاص بتيليجرام |
| `TELEGRAM_SESSION` | String Session لحسابك الشخصي |
| `TELEGRAM_GROUP_IDS` | أرقام القروبات مفصولة بفواصل |
| `BASE_CURRENCY` | افتراضي `USDT` |
| `MAX_OPEN_POSITIONS` | الحد الأعلى للصفقات، الافتراضي 4 |
| `TRAILING_PERCENT` | النسبة (0.02 تعني 2%) |
| `POLL_INTERVAL_SECONDS` | فترة تحديث الأسعار |
| `CANDLE_CHECK_INTERVAL_SECONDS` | فترة فحص شمعة 4H |
| `STATE_FILE` | ملف حفظ الحالة (اختياري) |

## حل مشاكل التشغيل السريعة
- إذا ظهر خطأ أن بعض المتغيرات مفقودة، سيتوقف البوت مع رسالة واضحة تحدد أسماء المتغيرات الناقصة.  
قم بإضافتها في Railway ثم أعد تشغيل الخدمة.

## تشغيل البوت محليًا
```bash
python app.py
```

## ملاحظات مهمة
- البوت لا يستخدم Futures أو Margin، فقط Spot.
- يجب تشغيله بشكل دائم حتى يعمل Trailing Stop المُدار من البوت.
